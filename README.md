# .github

SCFlow project issue and PR templates, contribution guide.

This repository is public by GitHub's rule for organization-wide defaults. It contains no private content.

## What it provides

Defaults applied to every repository of the organization that does not define its own version of the same file:

- Issue forms in [`ISSUE_TEMPLATE/`](ISSUE_TEMPLATE): bug report, task, feature request.
- A [pull request template](PULL_REQUEST_TEMPLATE.md).
- A [contribution guide](CONTRIBUTING.md).

A repository that defines its own `.github/ISSUE_TEMPLATE` folder uses none of the defaults for issue templates.
